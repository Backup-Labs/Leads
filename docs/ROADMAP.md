# Product Roadmap & Milestones — Leads SaaS

## Product Vision
To be the premier B2B Revenue Recovery & Lead Lifecycle Platform for emerging and high-growth markets, turning every inquiry into profitable revenue through automated follow-up tracking and clear pipeline visibility.

---

## Milestone 1: Core Foundation & MVP (Current Release)

### Focus: P0 (Essential Core)
- [x] Architecture & multi-tenant foundation design.
- [x] Dual-tier authentication (Session & Sanctum API) + Tenant context resolver.
- [x] Organization workspaces, invitations, and RBAC (`Owner`, `Admin`, `Manager`, `Sales`).
- [x] Complete Lead Lifecycle Management (Capture, assign, update, filter, search).
- [x] Interactive Kanban Sales Pipeline with drag-and-drop transitions.
- [x] Activity Timeline (calls, meetings, notes, stage audit logs).
- [x] Follow-up Scheduling & Overdue Reminder engine.
- [x] Deterministic Revenue Recovery Rule Engine (stalled deals, overdue follow-ups, expiring quotes).
- [x] Executive Dashboard & Real-Time Sales Analytics.

### Focus: P1 (Important Operations)
- [x] Quotation Engine (multi-item, taxes, discounts, status lifecycle).
- [x] Branded PDF Quotation Generation.
- [x] Secure tokenized public quotation links for client acceptance/rejection.
- [x] CSV Lead Import with column validation and export.
- [x] Automated email notifications for assignments and overdue follow-ups.

---

## Milestone 2: Automation & Expanded Channels (P2)
- [ ] **WhatsApp Business Cloud API:** Automated inbound lead ingestion from WhatsApp chat threads.
- [ ] **Meta / Instagram Lead Ads Webhook:** Direct synchronization of social advertising leads into tenant pipelines.
- [ ] **Website Embeddable Ingestion Widget:** Customizable inquiry form generating leads directly via public API.
- [ ] **Custom Pipeline Customization:** Multi-pipeline support for businesses with multiple service lines.
- [ ] **Multi-Currency Live FX:** Automatic conversion for international deals.

---

## Milestone 3: Mobile & Advanced Ecosystem
- [ ] Native Mobile App (iOS / Android) for sales reps in the field with offline call-logging.
- [ ] Automated SMS follow-up delivery via local telecom SMS gateways (e.g., Africa's Talking / Twilio).
- [ ] Payment Gateway Integration (Stripe, DPO Pay, Flutterwave, MTN Mobile Money) for instant quotation settlement.
- [ ] AI-Powered Deal Risk Intelligence and smart follow-up message suggestions.
