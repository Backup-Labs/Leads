# REST API Architecture & Specification — Leads SaaS

## 1. Overview & Conventions

The Leads API adheres to **RESTful conventions**, structured under the `/api/v1/` prefix.

### Key API Standards
- **Content-Type:** `application/json`
- **Accept:** `application/json`
- **Authentication:** Bearer token (via Laravel Sanctum for API clients) or Cookie-based session for first-party Inertia clients.
- **Tenant Context:** Automatically resolved via authenticated user's active organization header `X-Organization-Id` or current session.
- **Standard Envelope:**
  ```json
  {
    "success": true,
    "data": { ... },
    "meta": { ... }
  }
  ```
- **Error Format:**
  ```json
  {
    "success": false,
    "error": {
      "code": "RESOURCE_NOT_FOUND",
      "message": "The requested lead was not found within this organization.",
      "details": []
    }
  }
  ```

## 2. API Endpoints

### 2.1 Authentication (`/api/v1/auth`)
- `POST /api/v1/auth/register` — Create user account & initial organization.
- `POST /api/v1/auth/login` — Authenticate and receive session or Sanctum token.
- `POST /api/v1/auth/logout` — Terminate session / revoke token.
- `GET /api/v1/auth/me` — Return authenticated user profile and memberships.

### 2.2 Organizations (`/api/v1/organizations`)
- `GET /api/v1/organizations` — List organizations user belongs to.
- `POST /api/v1/organizations` — Create a new organization workspace.
- `GET /api/v1/organizations/{id}` — Retrieve organization details & settings.
- `PATCH /api/v1/organizations/{id}` — Update organization preferences.

### 2.3 Team & Invitations (`/api/v1/organizations/{id}/members`)
- `GET /api/v1/organizations/{id}/members` — List members and roles.
- `POST /api/v1/organizations/{id}/invitations` — Invite new team member.
- `DELETE /api/v1/organizations/{id}/members/{userId}` — Remove member from organization.
- `PATCH /api/v1/organizations/{id}/members/{userId}/role` — Change member role.

### 2.4 Leads (`/api/v1/leads`)
- `GET /api/v1/leads` — Filtered & paginated lead collection (`?stage_id=`, `?source_id=`, `?assigned_to=`, `?status=`, `?search=`).
- `POST /api/v1/leads` — Create lead with duplicate check.
- `GET /api/v1/leads/{id}` — Full lead dossier with activities and quotations.
- `PATCH /api/v1/leads/{id}` — Update lead information.
- `DELETE /api/v1/leads/{id}` — Archive / soft-delete lead.
- `PATCH /api/v1/leads/{id}/stage` — Transition lead to new pipeline stage.
- `POST /api/v1/leads/import` — CSV bulk import with column mapping and validation.
- `GET /api/v1/leads/export` — Stream CSV export of authorized lead dataset.

### 2.5 Pipeline Stages (`/api/v1/pipeline/stages`)
- `GET /api/v1/pipeline/stages` — Get ordered list of stages with lead counts and aggregated value.
- `POST /api/v1/pipeline/stages` — Add custom pipeline stage.
- `PATCH /api/v1/pipeline/stages/{id}` — Rename, recolor, or flag won/lost.
- `POST /api/v1/pipeline/stages/reorder` — Persist drag-and-drop column order.

### 2.6 Activities & Follow-ups (`/api/v1/activities`, `/api/v1/follow-ups`)
- `GET /api/v1/leads/{id}/activities` — Retrieve chronological interaction history.
- `POST /api/v1/leads/{id}/activities` — Log phone call, meeting note, or email.
- `GET /api/v1/follow-ups` — List follow-ups (`?status=pending|overdue|completed`).
- `POST /api/v1/follow-ups` — Schedule reminder for a lead.
- `PATCH /api/v1/follow-ups/{id}/complete` — Mark follow-up done with resolution notes.

### 2.7 Quotations (`/api/v1/quotations`)
- `GET /api/v1/quotations` — List quotations with status filter.
- `POST /api/v1/quotations` — Create quotation with multiple line items.
- `GET /api/v1/quotations/{id}` — View quotation details.
- `PATCH /api/v1/quotations/{id}` — Edit draft quotation.
- `POST /api/v1/quotations/{id}/send` — Mark sent and email client PDF/link.
- `GET /api/v1/quotations/{id}/pdf` — Download rendered branded PDF.
- `GET /quotes/{token}` (Public) — Secure public view for customer acceptance/rejection.

### 2.8 Revenue Recovery (`/api/v1/recovery`)
- `GET /api/v1/recovery/alerts` — Active stalled opportunities and neglected leads.
- `POST /api/v1/recovery/alerts/{id}/dismiss` — Acknowledge or snooze alert.
- `POST /api/v1/recovery/scan` — On-demand recalculation of recovery risks.

### 2.9 Analytics & Metrics (`/api/v1/analytics`)
- `GET /api/v1/analytics/overview` — Dashboard summary cards (Leads, Win Rate, Pipeline Value, Won Revenue).
- `GET /api/v1/analytics/conversion` — Stage-by-stage funnel conversion velocity.
- `GET /api/v1/analytics/sources` — Lead volume and revenue generated by source.
- `GET /api/v1/analytics/team` — Sales rep performance, activity count, and won deals.
